# 举报后果分析

## 举报人侧

### 可能的保护

- **欧盟**：《举报人保护指令》(EU) 2019/1937 禁止报复、举证责任倒置（雇主须证明不利对待与举报无关）、身份保密义务、成员国提供免费咨询支持。
- **德国**：HinSchG 对泄露举报人身份者设有刑事责任。
- **美国**：特定领域有举报人保护（如 SOX、食品安全、交通），但**贸易类强迫劳动举报缺乏统一的金钱奖励与专属保护**；刑事举报人（FBI/HSI）可申请证人保护但门槛高。
- **平台侧（设计建议，当前未上线）**：短期会话、数据最小化和不要求实名；证据托管与端到端加密属于后置能力，不能向用户承诺已经存在。

### 现实风险（必须如实告知用户）

- **报复风险**：解雇、黑名单、签证不续（移民工）、暴力威胁。跨境工人（签证与雇佣绑定）风险最高。
- **身份暴露路径**：匿名渠道的技术痕迹（设备/网络）、证据细节反推（叙述内容仅个别人知情时）、公司内部排查。
- **心理成本**：等待期漫长且无反馈（官方渠道普遍不反馈进展）。
- **法律风险**：恶意虚假举报在欧盟可被处罚；窃取文件作证据可能涉法律责任。

### 平台的话术纪律

- 不美化举报（"一定会有正义结果"），不恐吓用户（"举报会毁掉你"）。
- 呈现为：可能的好处（启动执法、保护其他工人、自我记录）+ 现实成本（无反馈、时间、潜在风险）+ 用户自主决定。
- 提示通用数字安全建议，但不提供"教你去偷证据"类指引。

## 企业侧（查实后）

| 后果 | 法域 | 说明 |
|------|------|------|
| 货物扣留/排除/没收 | 美国 | WRO、UFLPA 扣查（累计超 1 万批、货值超 30 亿美元，截至 FY2024 公开口径） |
| 实体清单列入 | 美国 | 供应链实际断链，无自动移除 |
| 产品禁售/撤市/销毁 | 欧盟 | 2027-12-14 起，处置费用由经营者承担 |
| 行政罚款 | 德国 LkSG 最高全球营业额 2%；欧盟成员国各自的 FLR/CSDDD 罚则 | |
| 刑事责任 | 美（最高 20 年/终身）、英（终身）、中（3-10 年）、法、德等 | 针对行为人 |
| 资格与商业后果 | 美国 CTPAT 供应链资格取消、公共采购排除（德国）、品牌客户断单、投资者撤资、声誉损失 | |

## 对"重复举报"的说明

同一企业被多渠道举报时：各渠道独立处理（互不联通），不会自动合并或加重；企业侧的合规成本主要来自证据确凿程度而非举报数量。这是平台查重机制（内容指纹 + 事件聚类）的现实意义：把分散的佐证聚合为更完整的事件图景，而非制造重复计数。
