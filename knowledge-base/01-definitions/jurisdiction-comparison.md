# 主要法域对强迫劳动的定义对比

各法域对"强迫劳动"的定义均收敛于 ILO 第 29 号公约三要件（工作或服务 + 非自愿 + 惩罚威胁），差异在于规制路径（产品禁令 / 供应链尽调 / 刑法 / 劳动监察）。

## 定义对照表

| 法域 | 核心法律 | 定义基准 | 规制路径 |
|------|---------|---------|---------|
| 国际 | ILO C29 (1930) / C105 (1957) / P29 (2014) | 三要件原始定义 | 公约义务 + 代表程序 |
| 欧盟 | 基本权利宪章第 5 条、ECHR 第 4 条、FLR (EU) 2024/3015 | 援引 ILO C29 | 基本权利禁止 + 产品市场禁令 |
| 美国 | 19 U.S.C. § 1307、18 U.S.C. § 1589、UFLPA | 判例法 + 成文法组合 | 进口禁令 + 刑事责任 |
| 德国 | StGB § 233（人口贩运/剥削劳动罪）、LkSG | 援引 ILO | 刑法 + 供应链行政监管 |
| 英国 | Modern Slavery Act 2015 s.1 | s.1 罪名定义（接近 ECHR Art 4） | 刑法（最高终身监禁）+ 大企业透明度声明 |
| 法国 | Code pénal § 225-13、Loi de Vigilance 2017 | 刑法定义 + 警惕义务 | 刑法 + 民事警惕诉讼 |
| 澳大利亚 | Criminal Code Div 270、Modern Slavery Act 2018 | 刑法典定义 | 刑法 + 强制供应链报告 |
| 加拿大 | Criminal Code s.279.01、S-211 (2024) | 刑法典定义 | 刑法 + 强制供应链报告 |
| 中国 | 《劳动法》第 96 条、《刑法》第 244 条 | "以暴力、威胁或者限制人身自由的方法强迫劳动" | 劳动监察 + 刑事责任 |
| 日本 | 无专门强迫劳动罪名（2022 企业人权尽调指引为软法） | 依 ILO 框架 + 入国管理法 | 行政指引 + 劳动基准法 |

## 关键差异提示（供 agent 沟通使用）

1. **产品维度 vs 行为维度**：欧盟 FLR 禁的是"强迫劳动产品"的市场流通，美国 307 条禁的是进口，两国均不要求境内发生强迫劳动行为本身；而刑法路径（美 §1589、中 244 条、英 MSA s.1）惩罚的是发生在管辖关联范围内的强迫劳动行为。
2. **门槛差异**：供应链尽调类法律（CSDDD 5000 人+15 亿欧元、德 LkSG、英 s.54 营业额 3600 万英镑、澳 1 亿澳元、加 S-211）只约束大企业，中小企业的强迫劳动适用普遍刑法与劳动法。
3. **"出口"侧**：FLR 同时禁止在欧盟境内以强迫劳动生产的产品**出口**；美国 307 条只管进口侧。
4. **推定机制**：美国 UFLPA 对新疆相关货物建立了举证责任倒置（可反驳推定），这是全球唯一的大范围推定机制；其他法域均需个案证明。
5. **对举报人的影响**：同一行为在不同法域的定性、可举报渠道与后果完全不同（见 `05-reporting-channels/`），agent 须先确认用户所在国与供应链指向，再引用对应法域。

详细法条内容见 `02-laws/` 各专篇。
