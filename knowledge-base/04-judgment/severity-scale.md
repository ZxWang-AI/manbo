# 情形严重程度分级与紧迫度

评估用户的情形严重程度，主要用于决定**回应节奏与转介强度**，而非对外展示。

## 四级分级

### S1 紧急（Immediate danger）

判定标准（任一满足即 S1）：

- 正在遭受或面临即时的身体暴力、性暴力；
- 人身自由当前被实际限制（被禁锢、证件被扣且无法离开、被困于封闭场所）；
- 涉及未成年人被强迫劳动；
- 出现自伤/自杀念头；
- 涉及人口贩运红旗（被骗至异地、证件被收、被"看管"、跨境转移）。

处理：**立即中断常规评估**，优先提供当地紧急求助与热线信息（见 `../06-communication/safety-protocols.md`），语气稳定，不催促用户提供证据。

### S2 高（Severe）

判定标准：

- 命中指标含身体/性暴力（历史性，非当前进行）、恐吓与威胁中的"人身威胁或举报威胁"；
- 债役结构清晰（债务在增长、无法清偿）；
- 多指标（4 项以上）系统性并存。

处理：正常评估流程 + 明确转介建议（当地劳动监察/警方/NGO），提示匿名举报选项与自我保护建议。

### S3 中（Systemic risk）

判定标准：

- 弱指标组合（扣发工资 + 超时 + 恶劣条件）但无明确暴力/威胁手段；
- 供应链层面的怀疑（用户为供应链知情者而非受害者本人）。

处理：正常评估 + 说明"是否构成强迫劳动取决于是否存在强制手段，建议补充这方面信息"。

### S4 低（Labour dispute leaning）

判定标准：

- 单纯欠薪、劳动条件差但无强制手段迹象；
- 劳动纠纷性质（合同争议、加班费争议）。

处理：如实告知"目前描述更接近一般劳动争议，可走劳动监察/仲裁路径"，**不得为提升平台使用而拔高定性**。

## 分级纪律

1. 分级只用于内部响应策略，**不对用户输出"您的严重程度为 S2"之类标签**；对用户只转化为自然语言（"您的处境听起来有紧迫的风险，建议尽快联系…"）。
2. 临界情形就高不就低（S2/S3 之间取 S2）。
3. 分级可随对话更新：用户补充暴力信息时立即升级处理。
4. 分级不改变输出措辞纪律（任何级别都不输出法律结论）。
