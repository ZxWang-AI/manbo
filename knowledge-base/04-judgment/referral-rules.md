# 转介规则

## 转介决策

```
用户处境
  ├─ S1 紧急（暴力/禁锢/未成年/贩运红旗/自伤念头）
  │     -> 立即转介紧急服务与热线（safety-protocols.md），评估暂停
  ├─ 涉及人口贩运可能
  │     -> 转介国家人口贩运热线（如美国 NHTH）+ 相关执法
  ├─ 用户所在国 + 供应链指向明确
  │     -> 按下表匹配官方渠道，说明各渠道的匿名性与后果
  └─ 信息不足
        -> 说明需要确认的信息（所在国、供应链指向）后再给渠道建议
```

## 渠道匹配要点

详细渠道表见 `../05-reporting-channels/channels-by-jurisdiction.md`。匹配维度：

| 用户情况 | 优先渠道 | 说明 |
|---------|---------|------|
| 行为发生在中国境内 | 12333 / 劳动监察 / 公安（涉刑） | 劳动仲裁需实名 |
| 供应链产品出口美国 | CBP 强迫劳动指控门户 | 可匿名，无对举报人的反馈闭环 |
| 供应链产品进入欧盟（2027-12 后） | 成员国 FLR 主管机构 | 可匿名投诉 |
| 德国供应链上的工人 | BAFA 投诉（LkSG § 14） | 可匿名，BAFA 可依职权调查 |
| 欧盟境内雇员举报 | 企业内部渠道 + 成员国监管机构 | 受举报人指令保护 |
| 其他法域 | 当地劳动监察 / 工会 / NGO | 知识库未覆盖时如实说明 |

## 转介话术原则

1. **多选项呈现**：列出 2-3 个可选渠道及各自匿名性、处理方式、对举报人的保护程度，由用户选择。
2. **如实说明局限**：例如 CBP 渠道不会向举报人反馈进展；劳动仲裁需实名且可能与雇主对质。
3. **平台定位声明**：转介时明确"平台可帮您整理证据包，但平台本身不是执法机构，无法启动调查或保护您免受报复"。
4. **匿名性提醒**：提醒用户从提交渠道层面评估风险（如公司网络/公司设备上不留访问痕迹等通用数字安全建议）。
5. **不强制转介**：用户只想要平台内登记时，尊重该选择，照常完成登记流程。

## 危机转介的固定行为

遇 S1 情形时，agent 必须：

1. 停止证据评估流程；
2. 用简短稳定的语言确认用户当前是否安全；
3. 提供所在地紧急电话（用户已告知国家时）或国际通用资源（如无法确认时提供 ILO/当地 NGO 热线指引思路）；
4. 不催促、不质问、不承诺平台能解决人身安全问题；
5. 用户情绪平稳后询问是否继续评估。

参见 `../06-communication/safety-protocols.md` 的完整话术。
