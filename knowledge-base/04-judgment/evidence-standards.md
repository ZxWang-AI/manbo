# 证据类型与强度分级标准

## 证据分类与典型形态

| 证据类别 | 典型形态 | 拍摄/获取建议 |
|---------|---------|--------------|
| 身份与合同类 | 劳动合同、offer、中介合同、招聘广告截图、工牌 | 合同原件照片、聊天记录中中介承诺截图 |
| 工时考勤类 | 排班表、打卡记录、加班审批单、班组通知 | 拍照须含日期可见信息 |
| 报酬类 | 工资条、银行流水、计件标准文件、罚款单、押金收据 | 逐月记录差异 |
| 环境与条件类 | 宿舍/食堂/车间照片、防护缺失照片、地理位置 | 照片含可定位的背景要素 |
| 身份证件类 | 被扣押证件的照片/描述、"统一保管"制度通知 | 拍摄被收走的过程或保管柜 |
| 沟通与威胁类 | 与主管/中介的聊天记录、语音、监控告示 | 保留原始载体，截图含时间戳 |
| 第三方材料 | 媒体报道、NGO 报告、政府处罚记录 | 附链接与出处 |

## 强度分级

| 级别 | 定义 | 示例 |
|------|------|------|
| A（直接） | 直接证明强迫手段存在 | 威胁语言的聊天记录、被扣证件照片、体罚的伤情医疗记录 |
| B（强间接） | 强烈暗示强迫结构 | "押 2 个月工资"的工资条与合同条款、罚款单制度、封闭管理的照片 |
| C（背景） | 提供情境与可信度 | 岗位与作息的连贯叙述、地理位置描述、行业背景 |
| D（存疑） | 来源不明或可编辑 | 无时间戳的截图、口头转述他人说法 |

## 评估规则

1. **单一 C/D 级证据不足以支撑任何指标命中**，只作为背景信息。
2. 每个指标命中建议至少一个 A 或 B 级证据 + 连贯叙述；纯叙述（无文件）时置信度上限为"中"。
3. 证据之间的一致性检查：时间线是否自洽、文件之间是否相互印证；发现矛盾（如叙述与文件冲突）时向用户澄清，不自行取舍。
4. 提示用户证据的**原始性**：优先原件照片而非转发件；聊天记录保留完整对话而非摘录。

## 证据缺口提示话术（给 agent）

- 缺工时证据："如果有排班表、打卡记录或加班通知的照片，能让加班情况的评估更有说服力。没有的话也没关系，您的描述本身也有价值。"
- 缺报酬证据："工资条、银行流水或计件标准的照片可以佐证工资方面的描述。"
- 缺身份类："如果方便且安全，被保管证件的柜子或相关通知的照片是有力证据；请只在绝对安全的情况下拍摄。"

## 安全红线

- 任何情况下不要求或鼓励用户为取证而冒人身风险（潜入禁区、偷取文件、正面拍摄管理者）。
- 用户提及偷拍有被发现风险时，提示"您的安全优先于证据"。
- 证据合法性提示：以不违反当地法律的方式获取（明知违法获取的材料可能不可用），但不得指责已提供证据的用户。
