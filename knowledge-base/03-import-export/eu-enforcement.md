# 欧盟 FLR 调查与产品处置机制

## 调查启动路径

1. **主管机构依职权**：基于委员会**风险数据库**（risk database）、其他成员国主管机构共享的信息、海关数据启动。
2. **投诉启动**：任何自然人或法人可向成员国主管机构提交投诉（可匿名），投诉信息汇入风险数据库。
3. 欧盟委员会是否已上线单一门户、风险数据库及其公开范围，须在运行时打开官方页面核验；本文件不把动态上线日期硬编码为事实。

## 调查与决定流程

```
初步评估（preliminary phase）
  -> 有理由怀疑（substantiated concern）
  -> 正式调查（可要求经营者、供应链各方提供信息；经营者有申辩权）
  -> 最终决定（final decision）
```

最终决定可命令（按递进顺序）：

1. **禁止投放市场**或禁止出口；
2. **撤回**（withdraw）已上市产品；
3. **处置**：捐赠（人道主义等非商业目的）、改造（rectification，去除强迫劳动成分后可复入市场）或**销毁**；
4. 处置费用由**经营者承担**；
5. 违规信息必要时向公众披露（公司可能被点名）。

## 执法架构特点

- **成员国主管机构**（各国指定，通常为市场监督/海关部门）负责调查与决定，委员会负责协调。
- **域内互认**：任一成员国的决定对整个欧盟市场有效，货物在成员国间自由流通规则下被一致执行。
- 与海关衔接：适用日起，海关基于主管机构的风险数据库/禁令清单在进出口环节拦截。
- 处罚由成员国设定（effective, proportionate, dissuasive），无统一刑事罚。

## 证据标准（对举报人的启示）

- FLR 要求主管机构"有理由怀疑"即可深入调查，投诉只需提供可信的供应链线索与事实依据，不要求投诉人完成全部证明。
- 线索的可用性排序：具体公司/厂区标识 > 产品与批次信息 > 时间范围 > 强迫劳动事实描述 > 佐证文件。
- 出口侧同样被禁：产品从欧盟出口到他国市场（含经欧盟中转的第三国产品如涉及欧盟环节）须一并评估。

## 引用规则

- 时间纪律：2027 年 12 月 14 日前 FLR 不适用，agent 不得就该日前行为表述"违反 FLR"，只能说"将适用"。
- 涉欧盟用户的举报指引优先顺序建议：企业内部/成员国 CSDDD 监管机构（2029 起）或 FLR 主管机构（2027-12 起，产品向）-> 依据所在国转化法的劳动监察。
