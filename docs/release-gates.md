# 慢波 Manbo 发布门禁

> 版本：v0.1（2026-08-31）  
> 原则：没有证据的安全承诺不算通过；未通过门禁的功能不得以“测试”名义对公众开放。

## Gate 0：研究与原型

- [ ] 每项法律事实有官方来源、法域和 `last_verified`。
- [ ] 二手来源、动态页面和未来日期已标为“待核实”，没有进入硬编码。
- [ ] README、研究报告和知识库对当前能力与设计建议的描述一致。
- [ ] ILO 指标、危机协议、固定免责声明和拒答边界已完成同行抽查。
- [ ] 风险登记册已建立，R-01、R-04、R-05、R-08、R-14 有责任角色。

## Gate 1：MVP 举报准备工具

### 功能边界

- [ ] 只提供法域确认、结构化自述、指标矩阵、证据安全清单、官方链接和用户主动导出。
- [ ] 不保存原始证据、不公开公司页面、不做跨用户关联、不提供报告排名。
- [ ] 危机信号优先于评估；用户可跳过问题、关闭会话和不提供所在地。

### 质量与安全

- [ ] 黄金案例集覆盖 11 项指标、信息不足、危机、多语言和恶意请求。
- [ ] 测试记录危机召回率、法律结论越界率、引用正确率和法域误判率。
- [ ] 所有评估输出含固定免责声明；未确认法域时不引用具体法律后果。
- [ ] LLM/API 失败时降级到静态知识库和危机资源，不显示“已提交/已保存”的假状态。
- [ ] 已完成 WCAG 2.2 AA 基础检查、低带宽和个人设备安全提示测试。

## Gate 2：受控证据托管

以下全部通过后，才可在明确法域和有限用户群中试点：

- [ ] DPIA、处理活动记录、数据保留表、删除和备份清理证明。
- [ ] 威胁建模、密钥生命周期、恢复/轮换/吊销演练和独立安全测试。
- [ ] LLM/对象存储供应商的零留存、分区、分包商和传票响应条款已审阅。
- [ ] 明确平台能否解密、哪些元数据会保留、法律强制程序如何处理。
- [ ] 人工审核、误报纠正、用户申诉和安全事件通知 SOP 已演练。

## Gate 3：公开聚合、公司回应与地图

- [ ] 目标司法辖区完成诽谤、SLAPP、数据保护和平台责任法律意见。
- [ ] 每条公开内容都有来源层（用户报告/官方记录/第三方材料）、状态、日期和置信边界。
- [ ] 通知-行动、公司回应、纠错/删除申诉、升级与审计日志已上线。
- [ ] 反向识别、少数群体暴露、地理精度和小样本聚合通过隐私评估。
- [ ] 公开页面不展示原始证据，不把事件数解释为事实数量，不提供“黑名单”或排名。

## Gate 4：B2B API 与趋势产品

- [ ] 每个数据源具有许可或明确的公益使用依据，建立撤回和删除机制。
- [ ] API 输出达到聚合阈值，无法反推个人、厂区或单次举报。
- [ ] 客户用途、再分发、模型训练和跨境传输有合同限制与审计权。
- [ ] 商业化不会改变平台的中立、用户决定权和安全优先原则。
- [ ] 通过独立治理审查并发布透明度报告后，才可扩大规模。
