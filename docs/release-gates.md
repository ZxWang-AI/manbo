# 慢波 Manbo 发布门禁

> 版本：v0.1（2026-08-31）  
> 原则：没有证据的安全承诺不算通过；未通过门禁的功能不得以“测试”名义对公众开放。

## 当前路线：本地桌面工具

当前主线只发布本地优先的 Electron 工具，不发布在线案件平台。案件、对话、原始材料和衍生记录保存在用户设备；应用不内置共享 Key，不提供默认转发服务，也不替用户提交举报。用户自行配置的模型供应商可能按其条款处理已发送的提示词、提取文本或图片。

### Desktop Gate：对话、证据链与 BYOK

- [x] 普通问题可以不创建案件、不选择附件；案件打开不会自动把材料送入模型。
- [x] 发送前显示接收方、上下文、材料表示和任务范围；原件副本不由 agent 修改。
- [x] Provider Key 只通过主进程系统凭据边界使用，不进入渲染器、案件记录或日志。
- [x] 文本/PDF/图片分别经过表示和能力门禁；无法解析或不支持的材料在发送前拒绝。
- [x] Pi 会话禁用文件、终端、扩展、技能、资源发现和独立网络；三平台隔离未验证前不得开放自治工具。
- [ ] Windows、macOS、Linux 分别完成 Pi 与文件/终端隔离验证后，才可考虑开放工具能力。

以下 Gate 1–4 是旧的在线平台、托管和聚合路线，**不属于当前桌面工具的发布范围**；除非未来重新立项，不应据此扩展当前产品。

## Gate 0：研究与原型

- [ ] 每项法律事实有官方来源、法域和 `last_verified`。
- [ ] 二手来源、动态页面和未来日期已标为“待核实”，没有进入硬编码。
- [ ] README、研究报告、设计规格和原型对当前能力与设计建议的描述一致。
- [ ] ILO 指标、危机协议、固定免责声明和拒答边界已完成同行抽查。
- [ ] 风险登记册已建立，R-01、R-04、R-05、R-08、R-14 有责任角色。

## Gate 1：MVP 举报准备工具

### 功能边界

- [ ] 提供法域确认、结构化自述、指标矩阵、证据覆盖、官方链接、长期私密档案和用户主动导出。
- [ ] 原始材料仅以加密对象保存；单文件不超过 100 MB、单案件不超过 2 GB；危险格式隔离，不执行、不直接解析。
- [ ] 支持 AI 第一次初审、用户持续补充、双模式语音和管理员随时审核；AI/管理员状态不写成真实性或法律结论。
- [ ] 不公开公司页面、不做跨用户关联、不提供报告排名、不自动代用户提交。
- [ ] 危机信号优先于评估；用户可跳过问题、关闭会话和不提供所在地。

### 质量与安全

- [ ] 黄金案例集覆盖 11 项指标、信息不足、危机、多语言和恶意请求。
- [ ] 测试记录危机召回率、法律结论越界率、引用正确率和法域误判率。
- [ ] 所有评估输出含固定免责声明；未确认法域时不引用具体法律后果。
- [ ] LLM/API 失败时降级到静态知识库和危机资源，不显示“已提交/已保存”的假状态。
- [ ] 已完成 WCAG 2.2 AA 基础检查、低带宽和个人设备安全提示测试。
- [ ] 已完成对象存储加密、密钥轮换、删除/备份清理、恶意文件隔离和解析失败降级演练。
- [ ] 管理员访问、播放、下载、标注、修改和删除自动审计，用户可查看访问记录；审核意见与用户陈述/AI 版本分层保存。

## Gate 2：受控证据托管

以下全部通过后，才可在明确法域和有限用户群中试点：

- [ ] DPIA、处理活动记录、数据保留表、删除和备份清理证明。
- [ ] 威胁建模、密钥生命周期、恢复/轮换/吊销演练和独立安全测试。
- [ ] LLM/对象存储供应商的零留存、分区、分包商和传票响应条款已审阅。
- [ ] 明确平台能否解密、哪些元数据会保留、法律强制程序如何处理。
- [ ] 人工审核、误报纠正、用户申诉和安全事件通知 SOP 已演练。
- [ ] 长期托管的 100 MB/2 GB 限制、无默认到期时间、用户主动删除和备份清理均有可核验证据。

## Gate 3：公开聚合、公司回应与地图

- [ ] 目标司法辖区完成诽谤、SLAPP、数据保护和平台责任法律意见。
- [ ] 每条公开内容都有来源层（用户报告/官方记录/第三方材料）、状态、日期和置信边界。
- [ ] 通知-行动、公司回应、纠错/删除申诉、升级与审计日志已上线。
- [ ] 反向识别、少数群体暴露、地理精度和小样本聚合通过隐私评估。
- [ ] 公开页面不展示原始证据，不把事件数解释为事实数量，不提供“黑名单”或排名。

## Gate 4：B2B API 与趋势产品

- [ ] 每个数据源具有许可或明确的公益使用依据，建立撤回和删除机制。
- [ ] API 输出达到聚合阈值，无法反推个人、厂区或单次举报。
- [ ] 客户用途、再分发、模型训练和跨境传输有合同限制与审计权。
- [ ] 商业化不会改变平台的中立、用户决定权和安全优先原则。
- [ ] 通过独立治理审查并发布透明度报告后，才可扩大规模。
