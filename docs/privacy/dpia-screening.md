# Manbo DPIA 初筛记录

> 版本：v0.1（2026-09-02）  
> 结论：需要在真实托管或受控试点前完成完整 DPIA/处理活动记录；本文件不是法律意见。

## 1. 处理概览

平台拟处理用户主动提供的自述、对话、案件结构化字段、原始材料、录音、转写和用户修订版本，用于整理举报档案、展示证据缺口、提供法域渠道导航和用户控制导出。管理员可以在授权范围内查看、播放和下载，但平台不建立管理员查看/播放/下载的应用级访问历史。

数据默认与账户化名和案件绑定，用户主动删除前无默认到期时间。生产启用前必须让用户看到保留、删除、备份清理、供应商和法律强制程序边界，并提供可用的删除回执。

## 2. 高风险问题清单

| 问题 | 初筛结论 | 必须取得的证据/决定 |
|------|----------|----------------------|
| 是否包含健康、暴力、工会、移民身份、未成年人等特殊类别数据？ | 是，可能包含 | 处理必要性、适用法域合法基础和额外保护措施 |
| 是否存在生命/人身安全风险？ | 是 | 危机优先流程、静态资源、退出和升级 SOP |
| 是否进行跨境或模型供应商处理？ | 可能是 | 供应商、区域、分包商、传输机制、零留存/不训练条款 |
| 是否长期保存？ | 是，直到用户主动删除 | 保留表、备份清理证明、密钥生命周期和恢复演练 |
| 是否自动作出法律或资格决定？ | 否 | AI 仅初审和整理；不得评分、概率、排名或法律认定 |
| 是否公开、聚合或关联不同用户案件？ | MVP 否 | 任何未来变更需重新 DPIA、内容治理和法律审查 |
| 是否存在管理员访问透明度要求？ | 需法律审阅 | 当前不记录应用级查看历史的决定、RBAC 和剩余风险需明确告知 |

## 3. 数据流与最小化

1. 浏览器先显示隐私和安全提示；客户端不把本地路径或原始 bytes 发送给 AI。
2. API 服务端严格校验输入；PII 提示允许用户保留原文、使用脱敏版本或删除片段。
3. AI Gateway 仅收到用户确认后的文本和必要结构化上下文；模型配置中的区域、留存策略和模型别名由部署注入。
4. 原始材料与解析派生物分开保存；不能解析的材料可保存但保持 `saved_unread`，危险材料隔离且不进入判断。
5. 导出按字段预览和独立确认；平台不自动代用户提交外部机构。

## 4. 用户权利与控制

- 用户可查看、修订、继续补充、导出和主动删除自己的案件。
- 删除立即阻断后续读取，并对消息、材料、转写、派生物、索引、缓存、包裹密钥和备份清理排队。
- 用户可撤回外部共享同意；管理员修改与标注不覆盖用户或 AI 历史，可通过申诉追加更正。
- 平台不承诺绝对匿名；需提供设备、网络、公司设备和截图水印等现实风险提示。

## 5. DPIA 决定与待办

初筛建议按高风险处理活动准备完整 DPIA，并由隐私负责人/DPO、目标法域法律审阅人和安全负责人共同签字。以下项目完成前不得开启真实长期托管：供应商合同审查、区域与分包商清单、密钥轮换/吊销、备份恢复后删除、数据泄露响应、管理员最小权限、用户理解度和多语言文案审阅。
